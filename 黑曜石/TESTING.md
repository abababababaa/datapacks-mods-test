# 验证记录

环境：Minecraft Java 1.21.1、Yarn 1.21.1+build.3、Fabric Loader 0.16.14、Fabric API 0.116.6+1.21.1、JDK 21、Gradle 8.8。

最终测试同时加载了仓库内 `portable-crafting-3x3-1.0.0.jar`。18 项必需 GameTest 全部实际执行并通过，0 失败、0 跳过。它们启动临时测试世界，使用游戏实际注册表、配方管理器、实体、铁砧、战利品表和交易容器。

| 检查 | 验证内容 |
| --- | --- |
| 九个配方与标签 | 配方实际加载、正确材料产出、物品分类，原版黑曜石及爆炸抗性保留 |
| 属性及材料 | 耐久、效率、护甲、附魔能力、耐火、使用普通黑曜石修复 |
| 附魔台 | 每件装备 48 个不同种子的 30 级附魔，剑均无火焰附加 |
| 铁砧修复 | 九件装备每块修复 25% 最大耐久，原版经验与累积费用生效 |
| 生存铁砧附魔 | 火焰附加被拒绝，锋利正常加入 |
| 创造铁砧附魔 | 同样拒绝火焰附加，混合书的其他附魔可加入，输入书不被修改 |
| 全套及四种缺件 | 无限装备效果、熔岩免疫，逐一脱下四个部位均即时取消免疫 |
| 药水及进度 | 不覆盖或删除已有抗火药水，真实服务器玩家获得“？？？”进度 |
| 普通头颅 | 骷髅、凋灵骷髅、僵尸、苦力怕、猪灵各保证一枚，牛无独立头颅 |
| 自带燃烧 | 无附魔剑点燃，4 秒持续时间，切换武器后的燃烧击杀仍掉头颅 |
| 凋灵骷髅去重 | 64 次附有高抢夺等级的剑击杀，恰好 64 枚头颅，不叠加随机掉落 |
| 普通武器回归 | 铁剑击杀僵尸不强制掉头颅 |
| 宝箱 | 256 个种子均额外包含一件低耐久工具，五种工具都能抽到，原战利品仍在 |
| 新村民 | 三种大师职业恰有一项替换，默认交易数量不增加，重复读取不重复添加 |
| 已有村民 | 原交易对象保留价格、折扣、供需和次数，其他交易不变 |
| 玩家和龙首 | 玩家头颅保留 UUID，末影龙的致死剑击掉落龙首 |
| 原版玩法回归 | 普通黑曜石框架可生成下界传送门，附魔台配方正常 |
| 保存与到期 | 剑的短期燃烧归属保存/读取正常，到期后不再计入 |

客户端独立检查已通过：模组和护甲渲染器注册、九个模型 JSON 的 Minecraft 解析、四件护甲模型创建。在有 3×3 模组的客户端环境中运行，启动期间没有 Mixin 冲突。

GameTest 原始结果由本次命令写入 `build/gametest-results.xml`；构建目录不提交至仓库。

这些结果没有替代实际 Windows/PCL 画面验收。建议安装后确认物品图标、第一/第三人称持握、全套护甲外观、附魔光效和状态效果图标；尚未开展公网多人联机或其他渲染模组兼容测试。
