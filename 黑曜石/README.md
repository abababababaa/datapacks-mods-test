# 黑曜石装备

Minecraft Java **1.21.1** 的 Fabric 模组，包含黑曜石剑、镐、斧、锹、锄，以及头盔、胸甲、护腿、靴子。配方均使用原版黑曜石方块；没有注册替代黑曜石方块，也没有覆盖原版黑曜石、传送门或配方。

## 下载和安装

- [下载 obsidian-equipment-1.0.0.jar](https://github.com/abababababaa/datapacks-mods-test/raw/refs/heads/main/%E9%BB%91%E6%9B%9C%E7%9F%B3/obsidian-equipment-1.0.0.jar)
- [下载官方 Fabric API 0.116.6+1.21.1](https://maven.fabricmc.net/net/fabricmc/fabric-api/fabric-api/0.116.6+1.21.1/fabric-api-0.116.6+1.21.1.jar)

要求 Java 21、Fabric Loader **0.16.14 或更高**，以及 Fabric API **0.116.6+1.21.1 或兼容 1.21.1 的更新版本**。Fabric API 是单独的依赖模组，不是 Fabric Loader。

退出游戏，在 PCL 中打开目标 Fabric 1.21.1 实例的游戏文件夹，将上述两个 JAR 放进 `mods` 后重启。不要解压，也不要放进 `datapacks`。若已经有符合要求的 Fabric API，只保留一份即可。

启用版本隔离时，原有实例的安装位置通常为：

```text
C:\Users\<用户名>\Desktop\.minecraft\versions\1.21.1\mods
```

新建的 Fabric 实例请使用它自己的实际文件夹。单人游戏安装客户端即可；联机需要服务器和所有客户端安装本模组及 Fabric API。可以与仓库内的 `3x3` 模组同时使用，已经完成组合加载和游戏逻辑测试。

## 制作及修复

所有配方与对应木/石/铁工具、铁护甲的原版形状一致，把主要材料替换成 **黑曜石方块**。工具手柄仍使用木棍。斧和锄的配方允许左右镜像。

| 装备 | 黑曜石用量 | 木棍用量 |
| --- | ---: | ---: |
| 剑 | 2 | 1 |
| 镐 | 3 | 2 |
| 斧 | 3 | 2 |
| 锹 | 1 | 2 |
| 锄 | 2 | 2 |
| 头盔 | 5 | 0 |
| 胸甲 | 8 | 0 |
| 护腿 | 7 | 0 |
| 靴子 | 4 | 0 |

获得黑曜石后会解锁配方书中的九个配方。使用工作台，或已安装的随身 3×3 合成区制作。

九件装备都支持附魔台、附魔书及铁砧合并。**黑曜石剑不能获得火焰附加附魔**，包括创造模式铁砧；混合附魔书中的其他合法附魔仍可使用，原附魔书不会在计算结果时被修改。管理员使用直接修改物品组件的命令仍可绕过正常玩法规则。

所有装备使用普通黑曜石在铁砧上修复，按原版规则每块最多修复最大耐久的四分之一，保留经验消耗、累积修复惩罚和“过于昂贵”等限制。不接受哭泣的黑曜石作为材料。相同装备也可按原版规则合并修复。

## 属性

无附魔、无其他增益时，工具攻击伤害包含玩家基础 1 点伤害。攻击速度与对应下界合金工具相同。

| 工具 | 攻击伤害 | 攻击速度（次/秒） | 耐久 |
| --- | ---: | ---: | ---: |
| 剑 | 9 | 1.6 | 2300 |
| 镐 | 7 | 1.2 | 2300 |
| 斧 | 11 | 1.0 | 2300 |
| 锹 | 7.5 | 1.0 | 2300 |
| 锄 | 2 | 4.0 | 2300 |

采掘工具在适用方块上的效率为 **10**（下界合金为 9），可正确采掘的方块范围与下界合金相同。剑保留原版剑对蛛网等方块的专门行为。所有装备附魔能力为 **18**（下界合金为 15）。

## 剑的特殊效果

- 有效近战命中自带 **4 秒燃烧**，相当于火焰附加 I，不需要附魔。完全被盾牌挡住的攻击不会触发。
- 使用黑曜石剑击杀有对应原版头颅的生物，必定掉落一枚头颅。支持骷髅、凋灵骷髅、僵尸、苦力怕、猪灵、末影龙、玩家；玩家头颅保留其资料和皮肤信息。
- 没有独立原版头颅的生物不凭空生成头颅，例如牛、尸壳、流浪者、溺尸、猪灵蛮兵等。
- 剑造成的短暂燃烧随后击杀目标，也会掉落头颅；切换手持物品不会抹去这段燃烧的归属。归属会随燃烧时间到期，并支持实体保存/加载。
- 凋灵骷髅不会因为原版随机掉落与保证掉落叠加而重复掉两枚头颅。其他普通掉落保留。
- 头颅掉落遵守 `doMobLoot` 游戏规则，其他武器的掉落规则不变。

## 全套效果及进度

穿戴四件黑曜石护甲时获得无限时长的 **抗火（黑曜石套装）**，脱下任意一件立即失去装备提供的免疫，效果图标在下一个实体刻移除。头盔、胸甲、护腿、靴子必须穿在对应位置；放在背包中不算。

装备抗火与药水的抗火分开保存，因此脱装不会删除仍有效的抗火药水。全套仍在身上时，喝牛奶无法永久取消装备能力。实际免疫和相关原版抗火查询即时根据穿戴状态判断。

首次穿齐四件时获得挑战进度 **“？？？”**，显示于原版故事进度分支，完成前隐藏。仅把整套放进背包不会获得进度。

## 村民与废弃传送门

工具匠、武器匠、盔甲匠达到大师级后，会把一项钻石装备交易替换为同类型的附魔黑曜石装备。替换保留原价格、折扣、供需、使用次数和经验奖励；已经存在的满级村民在下次读取交易时也会应用。重复查看或补货不会不断添加装备交易。

Java 1.21.1 默认规则中，工具匠大师级只新增钻石镐交易，武器匠只新增钻石剑交易，盔甲匠新增钻石头盔和胸甲两项。因此前两者替换各自的大师级装备，盔甲匠随机替换两件中的一件；较低等级已解锁的交易保留。实验性交换平衡或已有自定义交易导致没有钻石可替换时，补充一项对应职业的附魔黑曜石装备交易。

废弃传送门战利品表额外固定抽取 **一件黑曜石工具**，剑、镐、斧、锹、锄等概率，剩余耐久只有 **1%～5%**。原箱子其他战利品保留。此规则作用于尚未生成战利品的箱子；已打开过的箱子不会自动刷新。

## 外观

工具和物品图标的形状由原版铁装备轮廓生成薄立体模型，装备材质直接引用 `minecraft:block/obsidian`，木柄引用橡木材质。穿戴护甲使用带面部开口、袖口和靴子结构的模型，直接采样原版黑曜石纹理，支持附魔光效。

没有重绘或替换原版黑曜石纹理。资源包更换黑曜石材质时，新装备会随之使用该材质。图标与原版护甲形状不是逐像素相同的贴图重着色；它们是使用黑曜石表面的立体模型。

## 开发及验证

使用完整 JDK 21，在本目录执行：

```powershell
.\gradlew.bat build
.\gradlew.bat runGametest runSmokeClient -x downloadAssets
```

Linux/macOS 把 `.\gradlew.bat` 替换成 `./gradlew`。可安装产物为 `build/libs/obsidian-equipment-1.0.0.jar`；`-sources.jar` 仅为源码。

同时加载仓库中的 3×3 成品进行测试：

```sh
./gradlew build runGametest runSmokeClient -PwithPortableCrafting -x downloadAssets
```

本次在 Minecraft 1.21.1 的实际测试服务器中通过 **18 项必需 GameTest**，包括真实配方加载、附魔、铁砧修复、伤害/掉落、交易、进度和传送门；256 个不同随机种子的箱子生成均有且仅有一件低耐久工具。客户端通过注册、模型解析和护甲模型创建检查。测试模组不打包进发布 JAR。

详细检查范围见 [TESTING.md](TESTING.md)。尚未在用户的 Windows/PCL 实例中进行最终画面确认，未验证其他第三方装备/渲染模组的组合。

资源生成脚本为 `tools/generate_resources.py`，仅重新生成资源时需要 Python 和 Pillow，参数为本机合法安装的 Minecraft 1.21.1 客户端 JAR。普通构建和游玩不需要 Python。

卸载会使存档中的模组装备失去对应物品定义；需要保留这些装备的世界请继续安装本模组。
