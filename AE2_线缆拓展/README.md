# AE2 线缆拓展

目标：Minecraft Java 1.21.1、NeoForge 21.1.169 或更高的 21.1.x、官方 AE2 **19.2.18**。这是 NeoForge 附属模组，不用于 Fabric。AE2 本身还需要 GuideME 21.1.1 或兼容的较新版本。

**当前工作区更新：1.1.0 源码已实现，静态检查通过，尚未编译或执行本版本游戏测试，也尚未推送。目录内的 1.0.0 JAR 是旧版，不包含本次独立配方。** 详情见 [更新报告](更新报告.md)。

下面的 1.0.0 下载及 12 项通过记录属于上次发布版本；1.1.0 构建成功后应安装新版，并从 `mods` 移除旧版，避免重复安装同一模组。

已构建可安装的 [ae2-cable-tiers-1.0.0.jar](ae2-cable-tiers-1.0.0.jar)，并通过 GitHub Actions 的 12 项真实 AE2 游戏测试。构建来源、运行链接与 SHA-256 见 [验证结果](verification/result.json)，详细输出见 [构建和游戏测试日志](verification/build.log)。

## 安装

1. 使用 Minecraft 1.21.1 的 **NeoForge** 实例，NeoForge 至少为 21.1.169。之前的 Fabric 模组需要另一个 Fabric 实例运行。
2. 在该实例的 `mods` 中安装官方 AE2 **19.2.18** 及其依赖 **GuideME 21.1.1**（或兼容的较新版本）。
3. 下载本目录的 `ae2-cable-tiers-1.0.0.jar`，放进同一个 `mods` 文件夹，然后重启游戏。JAR 无需解压；多人游戏的服务器和客户端均需安装。
4. 在创造模式的“AE2 线缆拓展”标签页中查看全部三级线缆，或通过下面的合成配方获取。

[直接下载 JAR](https://github.com/abababababaa/datapacks-mods-test/raw/refs/heads/main/AE2_%E7%BA%BF%E7%BC%86%E6%8B%93%E5%B1%95/ae2-cable-tiers-1.0.0.jar)。如浏览器询问保存位置，选择保存文件。

## 全覆盖范围

五种实际承载 AE2 频道的线缆：水晶（AE2 Glass）、包层、智能、致密包层、致密智能。每种覆盖无色 Fluix 和全部 16 种染色，每个组合有三级，共 **255 种组合**。

二级直接复用 AE2 原有的 85 个物品及 ID，新增一级和三级共 170 个物品。石英纤维仅传输能量，本身不是承载 ME 频道的线缆，不改变其行为。

| 类型 | 一级 | 二级（原版） | 三级 |
| --- | ---: | ---: | ---: |
| 水晶 / 包层 / 智能 | 4 | 8 | 16 |
| 致密包层 / 致密智能 | 16 | 32 | 64 |
| 名称稀有度 | 普通：白色 | 稀有：蓝色 | 史诗：紫色 |

频道数指 AE2 默认频道模式。线缆的染色仍控制网络连接；稀有度只改变物品名称颜色，不改变线缆的染色或纹理。

## 1.1.0 材料及配方

一级和三级均可从原料独立制作，无需先制作二级线缆。以下表格均制作无色线缆；染色仍通过染料配方完成，覆盖全部 16 色。

| 产物 | 一级原料 | 三级原料 |
| --- | --- | --- |
| 4 根玻璃线缆 | 1 微石英纤维 + 4 福鲁伊克斯水晶碎块 | 4 普通石英纤维 + 2 福鲁伊克斯块 |
| 1 根包层线缆 | 1 同级玻璃线缆 + 2 任意颜色羊毛碎料 | 1 同级玻璃线缆 + 4 任意颜色羊毛 |
| 1 根智能线缆 | 1 同级包层线缆 + 2 红石粉碎料 + 2 荧石粉碎料 | 1 同级包层线缆 + 4 红石粉 + 1 荧石块 |
| 1 根致密包层线缆 | 4 同级包层线缆，2×2 有序 | 4 同级包层线缆，2×2 有序 |
| 1 根致密智能线缆 | 1 同级致密包层线缆 + 2 红石粉碎料 + 2 荧石粉碎料 | 1 同级致密包层线缆 + 4 红石粉 + 1 荧石块 |
| 1 根致密智能线缆，替代途径 | 4 同级智能线缆，2×2 有序 | 4 同级智能线缆，2×2 有序 |

除标注有序的配方外，上表均为无序。荧石块等于 4 荧石粉；福鲁伊克斯块等于 4 水晶，均采用实际原版/AE2 数值。相同制作路线的一级成本为二级的四分之一，三级为二级的四倍；AE2 原有两种致密智能路线之间的成本差异保留。

### 新材料

- 微石英纤维：玻璃／石英粉／玻璃竖排有序合成，产出 4 个。接受原 AE2 的 `c:glass_blocks/cheap` 与 `ae2:all_quartz_dust` 标签；仅作材料，不可放置，不添加与普通纤维的直接换算。
- 福鲁伊克斯、赛特斯、下界石英、充能赛特斯水晶各自支持 `1 水晶 ↔ 8 同种碎块`，无序可逆。充能碎块保持独立身份。
- 红石粉、荧石粉各自支持 `1 原料 ↔ 8 同种碎料`，无序可逆。
- 全部 16 色羊毛分别支持 `1 羊毛 ↔ 8 同色碎料`，无序可逆，颜色不会丢失。包层配方接受任意颜色碎料。
- 共 23 个新增材料物品，统一使用自带“？”图标，并非缺失贴图。

碎料不加入原有整份材料标签；先还原为原材料，再用于 AE2 或其他模组的原有配方，避免一份碎料被当成一整份材料。

### 保留的换算与染色

- `1 根二级 → 4 根一级`，同类型、同颜色，无序。
- `4 根一级 → 1 根二级`，同类型、同颜色，工作台四角有序摆放，不能放成2×2。这避免与新增致密配方冲突，全部类型和颜色统一应用。
- `8 根二级 → 2 根三级`，同类型、同颜色，无序。
- `8 根同类型同等级线缆 + 1 份对应染料 → 8 根染色线缆`；染料使用标准 `c:dyes/*` 标签。
- 洗色沿用 `ae2:can_remove_color` 材料规则，输出保留等级。

所有 482 个配方使用附属自己的命名空间，不覆盖 AE2 原有配方；二级配方保持 AE2 原样。

## 网络及兼容设计

- 新物品创建 AE2 原有的线缆部件类，复用其网络节点、碰撞、部件宿主、侧面设备规则、智能灯、保存、拆卸和同步机制。
- 通过仅针对本附属新线缆的节点容量处理及相邻连接容量处理实现新上限。普通 AE2 设备、其他附属的自有节点和 AE2 二级线缆保留原容量。
- 原版二级物品通过 NeoForge 默认组件事件设置为蓝色 `RARE`，不注册替代的二级物品。
- AE2 的染色器和部件重染色操作会保留一级/三级身份；颜色互联及无色线缆行为仍使用 AE2 实现。
- AE2 的 x2、x3、x4 频道模式会按其倍率放大新线缆容量，无限频道模式继续无限。
- 保留无控制器网络的原版限制；三级线缆不会自动把无控制器网络升级成 16/64 频道网络。
- 高容量路径需要所有相关线缆都足够高级。混入一级或二级线缆仍形成容量瓶颈；P2P 隧道、机器等端点的原版限制没有被普遍提高。
- 智能线缆继续使用原有的 8/32 格灯纹理，以容量占比显示使用量；实际频道数由网络查询和 AE2 诊断工具读取。
- 物品模型直接以 AE2 对应颜色、对应种类的物品模型为父级，世界内也使用原部件渲染，不复制或修改 AE2 贴图。
- 新增线缆使用本附属的分等级标签，不并入 AE2 原配方的线缆标签，避免被原配方洗色为二级或产生材料转换漏洞。整合包可按等级使用 `ae2_cable_tiers:<种类>_tier_1` / `_tier_3` 标签。

由于需要对 AE2 内部频道节点及重染色逻辑做小范围 Mixin，目前依赖精确限定为已检查源码的 **19.2.18**。其他 AE2 版本需重新检查内部接口。与同时改写 AE2 核心频道算法的其他模组不能预先保证兼容，需要组合验证。

## 配置

NeoForge 服务器配置为世界的 `serverconfig/ae2_cable_tiers-server.toml`，服务器负责同步给客户端。默认值：

```toml
[channels]
basicTier1 = 4
basicTier3 = 16
denseTier1 = 16
denseTier3 = 64
```

编辑后重启世界/服务器。二级始终沿用 AE2 本身，不用附属配置覆盖；AE2 模式倍率另行作用。

## 构建与验证

需要完整 JDK 21 和网络可访问 NeoForge 官方 Maven、Maven Central、Gradle、Mojang 游戏资源。项目内有固定 Gradle 8.12 的 Wrapper 和发行包 SHA-256。

```powershell
.\gradlew.bat build
.\gradlew.bat runGameTestServer
```

Linux/macOS 使用 `./gradlew`。1.1.0 构建输出应为 `build/libs/ae2-cable-tiers-1.1.0.jar`。将构建结果放进 NeoForge 实例的 `mods`，客户端和服务器都需要安装。不要把开发源码文件夹直接放入 `mods`。

可重复生成资源并检查：

```sh
python tools/generate_resources.py
python tools/validate_resources.py /path/to/appliedenergistics2-19.2.18.jar
python tools/validate_materials.py
```

1.1.0 两项静态检查已通过：255 个线缆组合、193 个物品模型、482 个配方、22 组材料可逆性、16 色羊毛及独立主路线的精确四分之一/四倍成本。

`src/gametest` 现有 15 项测试，包括原有频道分配、混合路径、颜色及稀有度测试，以及新增的独立制作路线、材料还原、原有配方、所有染色/洗色配方检查。**1.1.0 尚未执行游戏测试**；旧版 1.0.0 的 12 项通过记录不能证明本次更新可运行。

当前运行环境禁止 Gradle 所需的本地套接字，沙箱外运行与网络授权均未获得，因此不能交付经过编译验证的新版 JAR。安装配置所保存的“允许全部域名”与本次命令执行的沙箱权限是不同层面。

开发缓存、测试世界和构建中间文件由 `.gitignore` 排除。测试代码不进入主模组 JAR。
