# 随身 3×3 合成（Fabric 模组）

适用 **Minecraft Java 1.21.1、Fabric Loader 0.16.14 或更高版本、Java 21**。无需 Fabric API。

这次文件是模组，不是原版数据包。它将生存/冒险模式的背包合成区从 2×2 扩展为 3×3，可直接使用工作台配方，例如箱子、熔炉和镐。

## 下载及安装（Windows 11 / PCL）

1. 下载本目录的 [`portable-crafting-3x3-1.0.0.jar`](https://github.com/abababababaa/datapacks-mods-test/raw/refs/heads/main/3x3/portable-crafting-3x3-1.0.0.jar)。不要解压。
2. 退出游戏，在 PCL 中选择安装了 Fabric 的 1.21.1 实例，打开其游戏文件夹，找到 `mods` 文件夹。不存在就新建。
3. 将 JAR 放进 `mods`，然后重新启动游戏。不是放进世界的 `datapacks`。

如果已开启 PCL 版本隔离，你提供的实例对应安装位置通常是：

```text
C:\Users\<用户名>\Desktop\.minecraft\versions\1.21.1\mods\portable-crafting-3x3-1.0.0.jar
```

如果没开启版本隔离，请以 PCL 打开的实际游戏文件夹为准。Fabric Loader 低于 0.16.14 时，先在 PCL 中更新加载器。

单人游戏只需在此实例安装。联机需要**服务器和每位客户端都安装本模组**；不支持仅客户端安装后连接原版/未安装本模组的服务器。服务器不需要图形环境。

此前的工作台换深层钻石矿石数据包仍可一起使用，本模组不会替你安装那个数据包。

## 界面与交互

- 面板从 176 像素加宽到 204 像素，高度保持 166 像素。人物、装备、副手、背包和快捷栏的位置保持原布局；3×3 输入区移至右上方，输出和配方书按钮放在其右侧。
- 原版 46 个槽位的网络编号不变，新增 5 个合成槽位追加在末尾，避免改变装备、副手和快捷栏编号。
- 支持配方书自动填充、九格配方提示、输出合成和输入材料的 Shift 点击。关闭背包时，原版清理逻辑会处理全部九格材料。
- 配方书在窄窗口时沿用原版的切换显示方式。状态效果区域按新面板宽度定位。
- 创造模式保留原版创造界面，不额外显示合成区；新增槽位会和原版合成槽位一样隐藏。
- 同时修改背包、合成槽位或配方书的其他模组可能产生兼容性问题，尚未做此类组合测试。

## 安装后验收

1. 在生存模式按 `E`，确认合成区为 3×3，人物、副手、背包、快捷栏和配方书按钮互不遮挡。
2. 用 8 个木板围一圈合成箱子；分别测试取走输出和 Shift 点击输出。
3. 在配方书中点击箱子配方，确认材料正确填入九格，装备栏没有改变。
4. 将材料放进第三列/第三行，Shift 点击退回背包；再放入材料后关闭界面，检查材料退回。
5. 在不同 GUI 缩放、窗口宽度下打开/关闭配方书，并检查状态效果提示。
6. 切换创造模式，检查原版创造背包与装备栏；再切回生存模式检查九格合成区。

此云端没有你的 PCL 游戏实例；尚未进行 Windows 实机画面、网络联机或第三方模组兼容测试。

## 从源码构建

已包含 Gradle 8.8 Wrapper 和发行包 SHA-256 校验。需要完整的 JDK 21，以及对 Fabric Maven、Mojang 资源服务和 Gradle/Maven 仓库的网络访问。

Windows PowerShell：

```powershell
cd 3x3
.\gradlew.bat build
```

Linux/macOS：

```sh
cd 3x3
./gradlew build
```

可安装产物为 `build/libs/portable-crafting-3x3-1.0.0.jar`，不要安装 `-sources.jar`。

运行无需显示器、不会创建世界的真实 Minecraft 类测试：

```sh
./gradlew runSmokeClient runSmokeServer -x downloadAssets
```

测试模组仅位于 `src/smoke`，不会打包进发布 JAR。它在 Fabric 的 preLaunch 阶段检查所有 Mixin 对实际 1.21.1 类的转换，然后使用隔离的背包容器验证九格配方、材料移动、配方书自动填充及客户端配方提示；不会启动游戏窗口或完整服务器。这些测试不替代上述实际游戏验收。

本次云环境通过了 `build`、2 项 JUnit 测试、CLIENT 和 SERVER smoke 检查。自绘界面纹理也已包含在 JAR 中。

## 卸载

关闭背包，退出游戏，再从 `mods` 移除 JAR。世界无需移除任何数据包，也不会删除已有物品。
